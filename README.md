# Where Brands, Creators, and Stories Meet

A modern, responsive website for an influencer marketing and talent management agency built with React, Vite, and Tailwind CSS.

## Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Modern UI**: Clean, minimal design with coral and navy color scheme
- **Interactive Elements**: Smooth scrolling navigation, modals, and form handling
- **SEO Optimized**: Proper meta tags, semantic HTML, and accessibility features
- **Performance**: Built with Vite for fast development and optimized builds

## Sections

1. **Hero Section**: Compelling headline with dual CTAs for brands and creators
2. **About**: Mission statement and core values (Authenticity, Creativity, Growth, Integrity)
3. **Services**: Two-column layout showcasing Influencer Marketing and Talent Management
4. **Approach**: Four pillars with examples (Data + Creativity, Long-Term Partnerships, etc.)
5. **For Brands**: Dedicated section with benefits and CTA
6. **For Creators**: Dedicated section with benefits and talent application modal
7. **Case Studies**: Two hypothetical but realistic case studies with metrics
8. **Why Us**: Six key differentiators
9. **Future Vision**: Thought leadership on the future of storytelling
10. **Contact**: Comprehensive contact form with newsletter signup
11. **Footer**: Links, social media, and company information

## Getting Started

### Prerequisites

- Node.js (version 16 or higher)
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`

### Building for Production

```bash
npm run build
```

The built files will be in the `dist` directory.

## Customization

### Placeholders to Replace

- `{{LOGO}}`: Replace with your actual logo file
- `{{HERO_IMAGE}}`: Add hero background images
- `{{CASE_LOGO_1}}` and `{{CASE_LOGO_2}}`: Add case study brand logos
- `{{EMAIL}}`: Replace with your contact email
- `{{SOCIAL_HANDLES}}`: Replace with your social media handles

### Colors

The website uses a custom color scheme defined in `tailwind.config.js`:
- Primary: Navy blue (#0F172A)
- Coral: Accent color (#FF6B6B)
- Secondary: Light gray (#F1F5F9)

### Fonts

- Headlines: Poppins (Google Fonts)
- Body text: Inter (Google Fonts)
